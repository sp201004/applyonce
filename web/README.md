# ApplyOnce web app

The ApplyOnce dashboard is a Next.js application for account access, profile management, resume upload, and browser-extension connection.

## Local development
1. Copy `.env.example` to `.env.local` and provide your own environment values.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.
4. Open `http://localhost:3000`.

## Validation
```bash
npm run lint
npm run build
```

Environment files are ignored by Git. Do not commit credentials or service secrets.
